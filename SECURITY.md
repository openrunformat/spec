# Security policy

Open Run Format files may come from anyone, so readers must handle hostile input safely. If you find a security problem
in the specification or in the .NET reference library — for example, a file that makes a reader crash, hang, use
unbounded memory or write outside the expected place — please **do not open a public issue**. Report it privately
through GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
(the **Security** tab of this repository, «Report a vulnerability»).

Please include a sample file or steps to reproduce, the library version or commit you tested, and the impact you see.
We will acknowledge the report, keep you informed and credit you in the fix if you wish.
