# Open Run Format logo

| File | Use |
|---|---|
| `openrunformat-icon.svg` | Icon with rounded corners (vector source, viewBox 64×64) |
| `openrunformat-avatar.svg` | Square variant for avatars (platforms round the corners themselves) |
| `openrunformat-512.png` | 512×512 PNG of the avatar |

Colours: slate `#1E2A38` (braces), orange `#E48312` (trace). The braces stand for open, readable data; the trace for a run.

## Using the name and logo to show compatibility

Any software that reads or writes `.runlog` / `.runmeta` files **may use the "Open Run Format" name and this logo to
indicate compatibility**, provided that:

1. it passes the conformance suite in [`conformance/`](../conformance) for what it claims (reading, writing or both);
2. it does not suggest that it is made, endorsed or certified by the Open Run Format project;
3. the logo is not modified other than scaling (keep the colours or use a single-colour version in slate or white).

A suggested label: **"Compatible with Open Run Format 1.x (reader/writer)"**, linking to
<https://github.com/openrunformat/spec>.

The logo files are distributed under the same licence as this repository (Apache-2.0); this section describes how
the project asks the name and logo to be used.
